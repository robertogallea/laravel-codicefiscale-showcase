# Frontend stack: Livewire + Flux (Pro)

The showcase needs live birthplace search, tabbed calculate/decode, tooltips on the code breakdown, and progressive disclosure (matching-against-a-person) without hand-rolling a JSON API. We considered Blade + Alpine + small fetch endpoints (what a sibling prototype used) and Inertia + Vue/React. We chose Livewire 3 with Flux: it's the idiomatic Laravel-way path already established in this repo's conventions, and avoids maintaining a separate API surface.

**Correction during implementation**: the original version of this ADR assumed Flux's *free* tier included combobox, tabs, and tooltip components. It doesn't — checking the installed `livewire/flux` v2.16.0 package directly (its own README, and which Blade stubs ship in `livewire/flux` vs. `livewire/flux-pro`) showed Tooltip, Button, Dropdown, Icon, and Separator are free, but Tabs and the Select `combobox` variant this design needs are Pro-exclusive. The maintainer holds a Flux Pro license, so we required `livewire/flux-pro` instead of working around the gap with hand-rolled components. Anyone extending this app should assume Flux Pro is a real, licensed dependency, not an incidental one — components like Tabs and Combobox will not work without it.
